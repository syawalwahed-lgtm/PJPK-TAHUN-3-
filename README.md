## GitHub Pages
1. Buat repository baharu di GitHub.
2. Muat naik `index.html`, `style.css` dan `script.js`.
3. Buka **Settings → Pages**.
4. Pilih deployment daripada branch `main` dan folder `/root`.
5. Simpan. Pautan GitHub Pages akan dipaparkan oleh GitHub.
6. Jana QR Code menggunakan pautan GitHub Pages tersebut.
